## 🌟 Featured Project

### 📡 MyMektan — IoT-Based Asset Monitoring & Telemetry Platform (2026)
> Production-deployed IoT monitoring system built end-to-end, from edge devices to dashboard

- **Data Pipeline:** Node.js + HiveMQ Cloud (MQTT) streaming real-time telemetry every 5 seconds
- **Database:** PostgreSQL with Haversine Formula-based backend logic for distance & area estimation
- **Dashboard:** Vue.js web app with real-time geospatial tracking, fleet analytics, and route playback
- **Result:** Zero data loss across 8 rounds of field testing over 4 months
